TableMacro

Tap your desk. Your Mac responds. TableMacro listens through the built-in microphone, classifies the tap locally, and runs the action assigned to that zone.

View on GitHub Read the docs

Four zones, one desk

TableMacro turns the desk immediately around a MacBook into four assignable tap zones — rear and front, on each side. Ten calibration taps per zone teach it your desk's acoustics; after that, a tap runs whatever action you assigned.

What each tap can do

Visual only

Highlights the zone with no side effect.

Sound & speech

Play a system sound, copy text, or speak it aloud.

Open something

A website, a Shortcut, an app, or a file/folder.

Automate

Run a shell command, or capture a screenshot to the clipboard.

How it works

  1. Calibrate: ten natural taps in each of the four zones, with live retry guidance for weak, noisy, or clipped taps.
  2. Save the profile and assign an action to each zone.
  3. TableMacro listens continuously for a short, high-contrast acoustic impulse, rejects sustained sounds like speech, and classifies accepted taps against your calibrated profile.
  4. Run a guided 60-tap accuracy test any time to measure real per-zone accuracy, latency, and a confusion matrix.

TableMacro is a research prototype: automated DSP tests pass, but real accuracy still has to be measured on each MacBook, desk, and room.

Privacy by construction

All processing happens on the Mac. Raw audio is discarded after feature extraction by default — profiles store classifier parameters, not recordings — and nothing is uploaded unless an assigned action explicitly opens an external destination.
